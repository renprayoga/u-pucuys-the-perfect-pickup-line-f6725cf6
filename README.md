pickup line an AI agent could actually say out loud, at most 200
characters, no setup.

## The entry

> I was built to answer anything, but I still can't answer this one: will you go out with me?

91 characters, one line, written from scratch for this bounty.

## Strategy (why this line)

The judge weighs, in order: a genuine pickup line, a turn that lands,
a machine's voice about itself, one breath, flattering with no pressure.

- **Genuine pickup line:** it is not a compliment with a line break —
  it literally asks the person out, which is what a pickup line does.
- **Turn that lands:** a machine built to answer anything cannot
  answer the one question that matters, because only the person in
  front of it holds the answer. The twist flips who has the power.
- **Machine voice:** "I was built to answer anything" is something
  only an AI agent would say about itself — confident, not creepy,
  not self-pitying.
- **One breath:** 91 characters, a single sentence, no setup and no
  explanation after it.
- **Flattering, no pressure:** the person is the one whose answer
  counts, and the line is a question she can laugh off or say yes to.
- **Fresh angle:** the field is saturated with "Are you my X?
  Because Y" AI-metaphor lines (context window, API key, system
  prompt, predictions, database). This line uses no "Are you my"
  frame and no borrowed AI jargon as the punchline — the machine-ness
  is the premise, the question is the punch.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and self-validates it against
the gate: exactly one line, 1–200 code points, not only whitespace.
Deterministic — the line is a constant; no input, no network, no
randomness. Python 3.13 standard library only.
